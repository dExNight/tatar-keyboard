## Сборка и воспроизводимость

Артефакт собран пайплайном `scripts/release_pack.sh`: `./gradlew clean
assembleRelease -PskipReleaseSigning` → `zipalign -f -z 4` → `zipalign -c 4` →
`apksigner sign` (ключи из `keystore.properties`, v2-only, пароль env:-формой)
→ `apksigner verify`. Два независимых прогона полного пайплайна дали побайтно
одинаковый APK: SHA-256 `6d0038a1…b519`, размер 1 796 107 Б (`cmp` без
различий). Оговорка про пин версии build-tools из аудита 1.9.9 в силе. В релиз
вкладывать файл из `dist/`.
