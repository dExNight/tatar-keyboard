# Майлстоун v1.1 — «Татарский первым классом»

Старт: 2026-07-20, после завершения iOS-редизайна. Ведение — docs/ (GSD обойдён по решению
пользователя). Конвейер каждой фазы: implement → build+gates → adversarial review
(fail-closed гейт) → commit → push.

Рамки: ноль новых зависимостей, без INTERNET, APK ≤ 3 МБ (сейчас ~822 КБ), ноль аллокаций
в draw-цикле, юр-рамки iOS-стиля. Новые строки — en base + ru + tt.

## Фаза T — татарская локализация интерфейса (values-tt)

Главный гэп против core value (вскрыт ревью v1.0): системная локаль tt даёт английский UI,
TalkBack по-татарски невозможен. Терминология — по глоссарию tt.wikipedia и локализации
Тиз.Яз: төймәсар (клавиатура), төймә (клавиша), көйләүләр (настройки), тел (язык),
хәреф (буква). Перевод вычитывает пользователь (носитель).

- [x] T1. values-tt/strings.xml — все user-visible строки приложения (настройки: заголовки
  экранов, пункты, summary; диалоги; back)
- [x] T2. values-tt/strings-setup.xml — онбординг (включая «сәлам»-подсказку)
- [x] T3. values-tt/strings-a11y.xml — TalkBack: spoken_letter_* для ә ө ү җ ң һ
  ПО-ТАТАРСКИ (нативные названия букв), служебные клавиши

- [x] T5. Отдельное ревью татарского текста агентом-лингвистом (терминология, орфография,
