# SIZE-CAMPAIGN — итоговый отчёт кампании ужатия APK (2026-09-01)

Кампания из трёх миссий по ресерчу `SIZE-OPTIMIZATION-RESEARCH.md`. Принцип:
только lossless — поменялась упаковка данных, не содержимое; идентичность
выдачи доказана полными сверками, а не выборочными. Релиз кампании —
**1.9.9 / versionCode 25** (`docs/APK-AUDIT-1.9.9.md`).

## Три миссии

| Миссия | Что сделано | Отчёт |
|---|---|---|
| SIZE-1 | Словари на **TATDICT schema 2**: блочный front-coding (K = 8) + u8-длины + varint-частоты; читатель schema 1 удалён | `SIZE-SCHEMA2.md` |
| SIZE-2 | Таблицы биграмм на **TATBIGR schema 3**: головы — дельта-varint словарных индексов (блочный индекс по 64), преемники — varint-индексы прямо в словарь, связка со словарём по raw SHA-256; читатель schema 2 удалён | `SIZE-SCHEMA3.md` |
| SIZE-3 | Baseline-профиль регенерирован под новые читатели; **zopfli-рекомпрессия** (`zipalign -z`) встроена релизным пайплайном `scripts/release_pack.sh` (unsigned → zipalign → apksigner sign v2-only), воспроизводимость сохранена; релиз 1.9.9 | этот файл + `APK-AUDIT-1.9.9.md` |

**Итог кампании: −320 044 Б, −15,3 %** (запас к потолку 3 МБ вырос с 33,4 %
до 43,6 %). Ресерч-оценка была ≈ −29 %; расхождение разобрано в финальной
пометке `SIZE-OPTIMIZATION-RESEARCH.md`: оценка считалась по сжатым ассетам,
а zip-deflate поверх более плотного потока дожимает хуже (системный эффект
обеих схемных миссий); zopfli дал −22 856 Б на unsigned вместо оценочных
~40 КБ — после schema 2/3 потоки уже плотные; lossy-вариант (u8-log2 частот,
ещё ~190 КБ) сознательно не делался.

## Доказательства lossless

- Словари: полное тождество разбора 100 000 слов × 2 (порядок, частоты),
  все 76 839 distinct-префиксов длины 1..5 через независимую модель читателя,
  побайтное совпадение наборов опечаток — `schema2_equivalence_check.py`,
  расхождений 0.
- Таблицы: все 20 202 головы (80 683 пары) пословно и по порядку идентичны
  schema 2 плюс 10 284 слова-не-головы молчат — `schema3_equivalence_check.py`,
  расхождений 0.
- Живой контроль на эмуляторе (1.9.9): tt «кил » → дә·әле·һәм,
  ru «я в » → этом·том·результате — совпадает с содержимым ассетов
  (скриншоты `docs/size-campaign/evidence/`).
