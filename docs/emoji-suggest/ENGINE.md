# EMOJI-SUGGEST, миссия 2: движок — эмодзи в полосе подсказок

Дата: 2026-09-01. Основание: `docs/EMOJI-SUGGEST-PLAN.md` (миссия 2),
`docs/EMOJI-SUGGEST-RESEARCH.md` (вариант A: append, курируемые данные, свой
тоггл). Данные — миссия 1 (`docs/emoji-suggest/DATA.md`, ассет
`emoji_suggest_v1.txt`, 3 825 записей ru+tt).

## Поведение

Пользователь набрал слово целиком и завершил его пробелом → если у слова есть
маппинг на языке активного сабтипа, эмодзи появляется в NEXT_WORD-полосе в
**хвостовой ячейке**. Тап по эмодзи-ячейке вставляет эмодзи через существующий
`InputLogic.commitPredictedWord`: ничего не удаляется, добавляется эмодзи +
автопробел («самолет » → тап ✈️ → «самолет ✈️ »). Replace-семантики нет.

## Приоритет ячеек (решение по риску из плана)

План фиксирует: «биграммы впереди, эмодзи только в свободную/крайнюю». Замер на
живых ассетах показал, что читать это как «только свободную» нельзя: все
контрольные слова миссии («самолет», «йөрәк», «кит») — головы биграммных таблиц
с ≥3 преемниками, свободных ячеек у них не бывает, и эмодзи не показывался бы
никогда. Принято чтение «крайнюю»:

- эмодзи **закреплён за хвостовой ячейкой**, когда маппинг есть;
- биграммы активного языка занимают передние ячейки в своём порядке — при
  наличии маппинга их не больше двух (третья — самая слабая — уступает хвост);
- слова companion-языка вставляются **перед** эмодзи-ячейкой
  (`applyCompanionResult` отделяет хвостовой эмодзи по признаку «в ячейке нет
  ни одной буквы» и дополняет словесную часть до room = 2);
- маппинга нет → полоса байт-в-байт как до фичи (три ячейки биграммам,
  companion заполняет с конца — прежний код без изменений);
- префиксная (PREFIX) полоса эмодзи не показывает никогда — только
  завершённое слово.

## Компоненты

- `latin/emoji/EmojiSuggestIndex.kt` — читатель ассета: Android-free,
  fail-closed (битая строка отбрасывается, нечитаемый ввод → EMPTY), ключ —
  `(язык, normalizeForLookup(слово))`, lookup без аллокаций (двухуровневый
  HashMap, язык из `subtypeId.substringBefore('_')`; `en` просто миссит).
  `filterTo` — отсев по glyph-probe, как у поиска эмодзи.
- `latin/emoji/EmojiSuggestSources.kt` — seam'ы `EmojiSuggestSource` /
  `EmojiSuggestPreparation` + продакшн-загрузчик `AssetEmojiSuggestPreparation`:
  один раз за процесс, на фоновом executor контроллера, читает ассет
  подсказок и `emoji_search_v1.txt` (единственное место, где живут имена
  эмодзи — для a11y), фильтрует через `PaintGlyphProbe`. Тоггл выключен →
  ассет не читается вообще.
- `SuggestionsController`: эмодзи-кандидат вычисляется синхронно внутри
  `applyNextWordResult` (наследует все session/token stale-защиты), гейт
  `EmojiSuggestGate` читается на каждый fill (как `AutocorrectGate`).
  Если таблица ещё грузится, полоса красится без эмодзи, а по готовности
  `onEmojiSuggestReady` дозаполняет её — но только если живое состояние
  редактора всё ещё тот же NEXT_WORD-момент (перепроверка контекста через
  EditorSurface, как на tap-пути). Ошибка загрузки терминальна и молча:
  полоса ведёт себя как раньше.
- Вставка — готовый `EditorSurface.commitPredictedWord` →
  `InputLogic.commitPredictedWord`: перепроверки живого контекста, пустого
  префикса и буквы после курсора остаются; `commitText` принимает строку
  целиком, суррогатные пары/VS16/ZWJ проходят как есть (проверено на ✈️ = U+2708
  U+FE0F и ❤️ = U+2764 U+FE0F на эмуляторе).
- A11y: `StripSurface.setSpokenCellLabels` (дефолтный no-op, фейки тестов не
  тронуты) → `InputView` → `SuggestionStripView.setSpokenLabels`;
  contentDescription эмодзи-ячейки = короткое имя эмодзи из
  `EmojiSearchIndex.nameOf` (новый метод, линейный поиск вне горячего пути).
  Имя русское — это язык коротких имён в search-ассете; при отсутствии имени
  TalkBack читает сам глиф.
- Long-press на эмодзи-ячейке молчит (в `LatinIME`: «забыть слово» для
  безбуквенной ячейки не предлагается).
- Тоггл: `Settings.PREF_EMOJI_SUGGESTIONS` (дефолт OFF, opt-in), подчинён
  мастер-переключателю подсказок через `Settings.readEmojiSuggestionsEnabled`
  (как автокоррекция), строка на экране Preferences после «Исправления слов»,
  строки base/ru/tt. Общие гейты наследуются конструкцией: эмодзи живёт только
  внутри полосы, а полоса требует eligible (пароли → `mShouldShowSuggestions`,
  `NO_PERSONALIZED_LEARNING`, известный курсор, сабтип со словарём).
  *Уточнение 2026-09-02 (миссия 4, M4b, `FIXES.md`): дефолт сменён на ON —
  opt-in не обнаруживался в поле; подчинение мастер-тогглу сохранено.*

## Гейты и «молчание»

- Тоггл выкл / поле пароля / NO_PERSONALIZED / en-раскладка / незагруженный
  или битый ассет / слово без маппинга — снаружи неотличимы: полоса ровно как
  до фичи, без тостов и диалогов.
- Stale-защиты: эмодзи-кандидат считается внутри применения результата,
  прошедшего `sessionId`/token-проверки; tap вяжется к `displayedContextWord`;
  `commitPredictedWord` сам перепроверяет живой контекст и пустой префикс.

`extractNextWordContext` (первое слово пустого поля); сама гонка attach тоже
реальна и закрыта перезапросом по завершении attach (`onBigramAttached`).*
