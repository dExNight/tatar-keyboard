# Майлстоун v2 — словарь и подсказки

Старт: 2026-07-21. План продолжает решения Фазы R из `docs/MILESTONE-v1.1.md`.
GSD не используется по прямому решению пользователя.

Статус на 2026-07-24: аналитическое ядро D0 выполнено и прошло независимое fail-closed
ревью (вердикт APPROVED_WITH_NOTES). D1a–D1e реализованы последовательно в
`codex/d1-sequential`; шесть находок независимого аудита D1 закрыты и повторно
отревьюированы (три линзы, все APPROVED_WITH_NOTES, блокеров нет). Artifact gate v1.2.0
пройден. Открытыми остаются device/performance UAT на реальном Samsung, вычитка татарских
строк носителем языка и внешняя публикация. Детальный frozen контракт и текущие gates
находятся в `PROPOSALS.md`, доказательства фаз — в `docs/DICTIONARY-D0.md` и
`docs/DICTIONARY-D1A.md`–`docs/DICTIONARY-D1E.md`.

Рамки: без INTERNET permission, NDK/JNI и новых Android-зависимостей; APK ≤ 3 МБ,
PSS клавиатуры ≤ 30 МБ, холодный старт < 400 мс; корпусные данные не коммитить.
Код и данные лицензировать/атрибутировать раздельно.

### Частичное свидетельство: эмуляторный UAT (не Samsung)

Прогон на AVD `tatar_keyboard_d1f_api35_arm64` (Pixel 3a, Android 15 / API 35,
google_apis arm64, headless, cold boot, `-gpu swiftshader_indirect`), установлен именно
`dist/tatar-keyboard-1.2.0.apk`.

- Функционально зелёное, включая проверки по свежим исправлениям интеграции: тап по
  кандидату после переключения ru→tt в уже открытом поле коммитит; заглавная даёт
  заглавные кандидаты и вставляет заглавным; при курсоре в середине слова полоса пуста
  даже для префикса, дающего три кандидата в конце слова; свайп-удаление и слайд по
  пробелу гасят показанные подсказки; в поле пароля полоса `GONE`; крэшей, ANR и
  tombstone нет.
- Высота полосы измерена количественно: `contentTopInsets` 1294 (подсказки ВЫКЛ) против
  1184 (ВКЛ) — ровно 110 px = 40 dp при density 440.
- Холодный старт 124–147 мс при бюджете 400 мс; APK 1,38 МБ при бюджете 3 МБ.
- **PSS-бюджет провален:** 33,4–33,6 МБ с включённой D1 против 29,2–29,4 МБ с
  выключенной при бюджете 30 МБ (чистый A/B, различается только `pref_tatar_suggestions`),
  то есть фича стоит ≈ +4,2 МБ PSS. Абсолютные значения на программном рендерере
  завышены; достоверна дельта. Нужен перезамер на реальном железе, прежде чем считать это
  релиз-блокером или артефактом эмулятора.
- Jank 25,93% при Slow UI thread = 0 — профиль софтверного GPU; бюджет «janky ~0%» не
  подтверждён и не опровергнут, статус NOT_COVERED.
- Не проверялось вообще: TalkBack и реальный обход virtual nodes, поворот и альбомная
  ориентация, split-screen, физическая клавиатура, direct boot, несколько пользователей,
  тёмная тема, другие плотности, смена системной локали. Отсутствие полосы в поле пароля
  подтверждено метрически (FLAG_SECURE не даёт скриншот).

Итог D1: функциональный и автоматизируемый scope D1a–D1e реализован, artifact gate
пройден; майлстоун целиком не завершён, пока не закрыты device/performance UAT на
реальном Samsung (включая перезамер PSS), вычитка носителем языка и публикация.
