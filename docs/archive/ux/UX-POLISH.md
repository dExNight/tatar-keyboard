# UX Polish — волна 1 (по итогам UX-исследования 2026-07-20)

Источник: три исследования (мировые практики UX клавиатур, татарский рынок/аудитория,
UX-аудит кода). Фильтр: дёшево + без риска + бьёт в подтверждённую боль. Пользователей ещё
нет — перестановки в настройках бесплатны; после релиза они ломают привычки.

Правила: минимальный дифф, стиль форка, новые user-visible строки — en base + values-ru
(values-tt — следующий майлстоун), ноль новых зависимостей, без INTERNET, каждая правка
оставляет проект собираемым.

- [x] P5.1 Проверить AudioAndHapticFeedbackManager: на каких API-путях используется ручной

  уже на 29+). Для путей с ручной длительностью — перейти на
  view.performHapticFeedback(HapticFeedbackConstants.KEYBOARD_TAP) как основной механизм

  ниже — performHapticFeedback(KEYBOARD_TAP) (константа доступна с API 3); тумблер
  vibrate_on сохранён, слайдера длительности в форке нет
