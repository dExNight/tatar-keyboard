## Что вошло в 1.9.3 поверх 1.9.2

`git diff --stat 9de069a4` по коду и сборке:

```
 app/build.gradle                                           |  4 ++--
 .../inputmethod/keyboard/internal/TimerHandler.java        |  8 +++++++-
 .../rkr/simplekeyboard/inputmethod/latin/LatinIME.java     | 14 +++++++++++++-
 3 files changed, 22 insertions(+), 4 deletions(-)
```

Содержательного кода — **две константы**. Всё остальное в этих строках — комментарии, объясняющие,
почему ноль нельзя использовать как идентификатор сообщения:

| файл | что изменилось |
|---|---|
| `LatinIME.java` | `MSG_UPDATE_SHIFT_STATE`: `0` → `3` |
| `TimerHandler.java` | `MSG_TYPING_STATE_EXPIRED`: `0` → `5` |
| `app/build.gradle` | версия |

Ни ресурсов, ни ассетов, ни манифеста, ни раскладок, ни разрешений. Данные не тронуты:
`git diff --stat app/src/main/assets` пуст, и в APK лежат те же шесть файлов тех же размеров, что
в 1.9.2 — оба `.tdict.zlib` (638 758 и 601 118 Б), обе таблицы биграмм (160 510 и 173 568 Б) и оба
`NOTICE.txt`.

Прибавка 24 байта — это разница длины строк версии и перепаковка zip, не содержимое.

**Проверять внимательнее всего стоит одно место:** `LatinIME.UIHandler`. Почему ноль ломал
доставку подсказок и почему любой ненулевой идентификатор её чинит — в `docs/SUGGEST-DIES.md`.

## Чего в этом аудите нет

* **PSS не мерен.** Правка не добавляет ни объектов, ни потоков, ни отображений; мерить было
  нечего, а бюджет памяти привязан к первому валидному замеру на живом устройстве, которого нет.
* **Живого телефона нет** — ни для дефекта, ни для старта, ни для памяти.
* **В стор ничего не ушло.** Ни `git push`, ни тега, ни релиза: артефакт лежит только в `dist/`.
