# Доказательства миссии tt-suggest-dies

Всё снято на эмуляторе `tt_suggest_a14` (Android 14, API 34, 1080×2280, density 440, headless),
в настоящем приложении — Google Messages, поле сообщения диалога. Живого телефона у разработчика
нет, поэтому **все числа здесь эмуляторные** и помечены как таковые в отчёте.

| Файл | Что это |
|---|---|
| `before-trace.txt` | Трассировка сборки ДО правки: `engine.result n=3`, а `applyResult` не вызывается ни разу |
| `after-trace.txt` | То же место ПОСЛЕ правки: `engine.result` → `ctl.applyResult` → `strip.show` |
| `before-measure.txt` | Замер ДО правки: 58 пустых полос из 66 нажатий |
| `after-measure.txt` | Тот же замер на исправленной debug-сборке: 0 из 66 |
| `release-1.9.3-measure.txt` | Тот же замер на собранной релизной 1.9.3: 0 из 66 |
| `before-band.png` | Полоса на `Друг другой прив` до правки — пустая, с разделителями |
| `after-band.png` | Тот же кадр на 1.9.3 — `привет · привести · привело` |
| `coldstart.sh`, `coldstart-1.9.3.txt` | Холодный старт 1.9.3: скрипт и сырые числа |

Трассировка писалась временной сборкой, в дереве её нет: она печатала только числа и флаги, ни
одной буквы набранного текста, и включалась сама только в debug-сборке.
