# Черновик письма в corpus.tatar

Статус: **ЧЕРНОВИК — НЕ ОТПРАВЛЕНО**. Адресат: `tatcorpus@gmail.com`.

Тема: Разрешение на производный частотный словарь для открытой татарской Android-клавиатуры

Здравствуйте!

Я разрабатываю Tatar Keyboard — бесплатную Android-клавиатуру с открытым исходным кодом,
которая работает полностью офлайн, без рекламы, аналитики и доступа в интернет. Код проекта
распространяется по лицензии Apache-2.0.

Я хотел бы использовать материалы corpus.tatar для подготовки производного словаря
татарских словоформ с частотами. Планируемая обработка: нормализация регистра и Unicode,
удаление служебных/нетатарских токенов, объединение одинаковых словоформ и отбор наиболее
частотных форм. Исходные тексты и предложения в приложение и репозиторий включаться не будут.

Прошу письменно подтвердить, разрешаете ли вы:

1. извлекать и обрабатывать словоформы и их частоты из corpus.tatar для этой цели;
2. распространять полученный производный частотный словарь вместе с APK, релизами и
   исходным кодом проекта;
3. позволять пользователям и форкам проекта копировать, изменять и повторно распространять
   этот производный словарь, в том числе через каталоги приложений, при сохранении указанной
   вами атрибуции и условий;
4. объединять полученные частоты с открытыми корпусами, например Leipzig Corpora Collection.

Приложение останется бесплатным, без рекламы и сбора данных. При этом каталоги приложений и
сторонние сборщики могут иметь собственные коммерческие условия, поэтому прошу отдельно
уточнить, допускается ли такое распространение.

Подскажите, пожалуйста:

- точный текст атрибуции и ссылку, которые нужно указывать;
- лицензию либо иные условия для производного словаря;
- есть ли ограничения на объём словаря, способы распространения или срок разрешения;
- вправе ли corpus.tatar предоставить такое разрешение на все материалы, используемые для
  расчёта частот.

Если разрешение возможно только при дополнительных условиях, буду благодарен за их точную
формулировку.
