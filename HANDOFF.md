## Главное в шести строках

1. **Приложение не изменилось функционально.** Всё, что предсказывало и рисовало
   раньше, предсказывает и рисует так же — проверено эмуляторными смоуками
   каждой фазы (свидетельства в `docs/restructure/evidence/`).
2. **Данные не тронуты.** Словари и таблицы биграмм — байт в байт те же,
   восемь пар размер/SHA-256 сверены с константами (`docs/APK-AUDIT-1.9.5.md`).
3. **Единственное пользовательское-видимое изменение** — из списка выбора убраны
   раскладки языков, кроме tt/ru/en. Префы удалённых сабтипов отваливаются мягко,
   проверено на эмуляторе.
4. **Обновление поверх 1.9.4 проверено:** `firstInstallTime` не изменился,
   распакованные словари не переинфлятились (те же имена с raw SHA-256),
   настройки и личный словарь на месте.
5. **Сборка не байт-в-байт воспроизводима:** две полные пересборки одного дерева
   дают APK одного размера с разным SHA-256. В релиз вкладывать файл из `dist/`.
6. **Lint теперь сторожит:** 22 предсуществующие ошибки закоммичены в
   `app/lint-baseline.xml`, любая новая ломает сборку (проверено зондом в 4а).

## Решения, принятые без оператора (обратимые)

1. **Состав локалей tt/ru/en** — прямое решение оператора, исполнено как есть.
2. **`data_extraction_rules.xml` сохранён**, хотя аудит предлагал удалить:
   на API 31+ `allowBackup=false` не закрывает D2D-перенос, закрывает именно этот
   файл (фаза 3а, отклонение 1). Удалена только legacy-редакция.
3. **Baseline-профиль оставлен без profileinstaller** — ноль runtime-зависимостей
   важнее, чем применение профиля на sideload; на Play-канале работает (фаза 4б).
4. **Запас до 3 МиБ — 32,9 %, а не 35,1 %**, как записано в журнале фаз 3б–4б:
   там арифметическая ошибка (формула та же, что в аудитах: свободное/потолок;
   1 033 953 / 3 145 728 = 0,3287). В CHANGELOG и аудите 1.9.5 — правильное число.
5. **Версия 1.9.5 / versionCode 21** (по заданию фазы 5).
