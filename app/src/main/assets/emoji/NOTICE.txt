Emoji panel data notice

The emoji panel asset app/src/main/assets/emoji/emoji_set_v1.txt is derived
from the Unicode emoji keyboard/display test data file emoji-test.txt for
UTS #51 (Unicode Technical Standard #51, Unicode Emoji), Emoji Version 15.1.

Source data: Unicode Emoji 15.1 emoji-test.txt
Documentation and usage: https://www.unicode.org/reports/tr51
Terms of use (Unicode Terms of Use / Unicode License):
  https://www.unicode.org/terms_of_use.html

Changes by the Tatar Keyboard project: the emoji-test.txt code-point table was
decoded, its declared version and a pinned SHA-256 were verified, and only
records with status "fully-qualified" were kept. From those, every sequence
containing a skin-tone modifier (U+1F3FB..U+1F3FF), a zero-width joiner
(U+200D), a regional indicator (U+1F1E6..U+1F1FF), or a tag code point
(U+E0020..U+E007F) was removed by code point. The surviving sequences were
grouped into category sections in file order and written as a deterministic
UTF-8 text asset. The original emoji-test.txt is not redistributed in this
repository; only this derived list of emoji sequences is shipped. The emoji
data remains subject to the Unicode Terms of Use referenced above; the
application's Apache-2.0 license does not replace those terms.

The emoji-search index app/src/main/assets/emoji/emoji_search_v1.txt is derived
from the Unicode CLDR annotation data, release 44: common/annotations/ru.xml,
common/annotations/en.xml, common/annotationsDerived/ru.xml and
common/annotationsDerived/en.xml.

Attribution and terms, quoted verbatim from the header of the source files:

  Copyright © 1991-2023 Unicode, Inc.
  For terms of use, see http://www.unicode.org/copyright.html
  SPDX-License-Identifier: Unicode-DFS-2016
  CLDR data files are interpreted according to the LDML specification
  (http://unicode.org/reports/tr35/)

Source data: Unicode CLDR 44 emoji annotations (Russian and English)
Documentation and usage: https://cldr.unicode.org
Terms of use (Unicode License / Unicode Terms of Use):
  https://www.unicode.org/copyright.html

Changes by the Tatar Keyboard project: the annotation files were decoded, their
pinned SHA-256s verified, and for every sequence already present in
emoji_set_v1.txt the Russian short name and keywords, followed by the English
ones, were collected, lowercased, de-duplicated and written as one tab-separated
line per sequence in the panel asset's own order. Sequences absent from the
panel asset are not indexed, so the search can never offer an emoji the panel
cannot draw. The original CLDR files are not redistributed in this repository;
only this derived index is shipped. The CLDR data remains subject to the Unicode
Terms of Use referenced above; the application's Apache-2.0 license does not
replace those terms.

Tatar (tt) is deliberately absent from the index: CLDR 44 ships eight
punctuation annotations for Tatar and no emoji annotations at all, so no Tatar
emoji keywords can be derived from this source.
