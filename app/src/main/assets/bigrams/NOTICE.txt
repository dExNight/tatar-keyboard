Tatar bigram (next-word prediction) table data notice

This table is derived from the Leipzig Corpora Collection downloadable Tatar
text corpora tat_mixed_2015_1M and tat_web_2018_1M (sentence-aligned files,
not the word-frequency lists used by the top-100k dictionary). A third
corpus, tat_news_2015_1M, was used only to measure the table's predictive
usefulness before it was built (docs/DICTIONARY-E5A.md) and contributed no
data to the shipped table itself.

Source catalogue: https://wortschatz.uni-leipzig.de/en/download/tat
Terms: https://wortschatz.uni-leipzig.de/en/usage

Recommended citation:
D. Goldhahn, T. Eckart, U. Quasthoff, "Building Large Monolingual
Dictionaries at the Leipzig Corpora Collection: From 100 to 200 Languages",
LREC 2012.

Changes by the Tatar Keyboard project: adjacent word pairs were counted
within sentence boundaries from the two source corpora, restricted to word
forms already present in the shipped tatar_top100k_v1 dictionary (a
separate, already CC BY 4.0-licensed component derived from the same
collection), ranked per head word, capped to the top 10,000 head words by
unigram frequency and the top 6 successors per head, packed into a
versioned binary format (schema 2, distinct from the dictionary's schema 1)
with SHA-256, and zlib-compressed. Full transformation record:
docs/DICTIONARY-E5B.md. This table data remains a separate CC BY 4.0
component; the application's Apache-2.0 license does not replace that data
license.
