Bigram (next-word prediction) table data notice

Both shipped tables are derived from downloadable text corpora in the Leipzig
Corpora Collection -- the sentence-aligned files, not the word-frequency lists
the top-100k dictionaries are built from.

Source catalogue: https://wortschatz.uni-leipzig.de/en/download
Terms: https://wortschatz.uni-leipzig.de/en/usage
License: Creative Commons Attribution 4.0 International (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

Recommended citation:
D. Goldhahn, T. Eckart, U. Quasthoff, "Building Large Monolingual
Dictionaries at the Leipzig Corpora Collection: From 100 to 200 Languages",
LREC 2012.

--------------------------------------------------------------------------------
tatar_bigrams_v1.tatbigr.zlib

Derived from the Tatar corpora tat_mixed_2015_1M and tat_web_2018_1M.
A third corpus, tat_news_2015_1M, was used only to measure the table's
predictive usefulness before it was built (docs/DICTIONARY-E5A.md) and
contributed no data to the shipped table itself.
Catalogue page: https://wortschatz.uni-leipzig.de/en/download/tat

Changes by the Tatar Keyboard project: adjacent word pairs were counted within
sentence boundaries from the two source corpora, restricted to word forms
already present in the shipped tatar_top100k_v1 dictionary (a separate, already
CC BY 4.0-licensed component derived from the same collection), ranked per head
word, capped to the top 10,000 head words by unigram frequency and the top 6
successors per head, packed into a versioned binary format (schema 2, distinct
from the dictionary's schema 1) with SHA-256, and zlib-compressed. Full
transformation record: docs/DICTIONARY-E5B.md.

--------------------------------------------------------------------------------
russian_bigrams_v1.tatbigr.zlib

Derived from the Russian corpora rus_news_2022_1M, rus_news_2019_1M, and
rus_wikipedia_2021_1M -- the same three corpora the russian_top100k_v1
dictionary is built from. A fourth corpus, rus_news_2024_1M, was used only to
measure the table's predictive usefulness before it was built and contributed
no data to the shipped table itself.
Catalogue page: https://wortschatz.uni-leipzig.de/en/download/Russian

Changes by the Tatar Keyboard project: the same transformation as above, with
the 33-letter Russian alphabet in place of the Tatar one and the shipped
russian_top100k_v1 dictionary as the vocabulary both halves of every pair must
belong to; same top 10,000 head words, same top 6 successors per head, same
binary format, same SHA-256 and zlib settings. Full transformation record:
docs/RUSSIAN-BIGRAMS.md.
