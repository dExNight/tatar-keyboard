# Plan 03-01 — Языки и переключение: long-press дубли + русская раскладка + три subtype (wave 1)

**Goal:** Три языка живут как subtypes tt_RU / ru / en_US: пользователь печатает на русской (стандартная ЙЦУКЕН, без пятого ряда) и английской (QWERTY) раскладках (LAYOUT-03); long-press на а/о/у/ж/н/х/э/г даёт ә/ө/ү/җ/ң/һ/ә/һ на обеих кириллических раскладках, плюс е→ё и ь→ъ (LAYOUT-02 + ревью F1); система видит три subtype и запоминает активный (SWITCH-01); тап по глобусу циклит tt→ru→en, long-press открывает пикер IME (SWITCH-02).

**User story:** As a татароязычный пользователь, переписывающийся по-русски и по-английски, I want переключать язык одним тапом по глобусу и доставать ә/ө/ү/җ/ң/һ long-press'ом даже на русской раскладке, so that один IME закрывает всю переписку — без переключения на Gboard.

Vertical-slice дисциплина: Task 1 — дубли на уже работающей татарской раскладке (видимый результат сразу); Task 2 — русская раскладка как данные; Task 3 — реестр связывает всё в тройку subtypes; Task 4 — человеческое имя «Татарча»; Task 5 — on-device чекпойнт. Ни одна задача не оставляет проект несобираемым.
