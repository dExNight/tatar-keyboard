# Plan 07-01 — iOS-стилизация баллона-превью и панели, верификация отклика на ACTION_DOWN (wave 1)

**Goal:** Закрыть UI-02/03/04 (SC1–SC4) по вердикту 07-RESEARCH.md: вся инфраструктура **уже работает в базе форка** — превью и панель рисуются in-layer через `DrawingPreviewPlacerView` (PopupWindow отсутствует в исходниках вообще), slide-to-select реализован полностью, хаптика+звук+подсветка срабатывают на ACTION_DOWN. Кодовая работа фазы — **чистый XML**: iOS-баллон превью (новый drawable + wiring в теме Tatar) + косметика панели; остальное — fail-capable-верификация вердиктов ресерча + bookkeeping.

**User story:** As a татароязычный пользователь, при нажатии буквы (включая ә ө ү җ ң һ пятого ряда) я мгновенно вижу iOS-баллон над клавишей, long-press открывает панель альтернатив с выбором скольжением, а клавиатура откликается вибрацией и подсветкой в момент касания — без лагов и обрезки на MIUI.

**Красная линия (zero-Java phase):** НИ ОДНОЙ правки `.java`/`.kt` — весь дифф фазы под `app/` ограничен `res/drawable/` + `themes-tatar.xml`; boundary — механический diff-чек от **fbfd66a**. НЕ вводить PopupWindow. НЕ флипать `config_default_sound_enabled` (решение пользователя: звук по умолчанию OFF, как в Gboard; тумблер — фаза 10). НЕ трогать 6 старых тем, `keyboard_key_feedback_background.xml`, `keyboard_popup_panel_background.xml`, `btn_keyboard_key_popup` (ими пользуются другие темы). Никаких ассетов Apple, зависимостей, INTERNET.

- **Решение пользователя (LOCKED):** `config_default_sound_enabled` остаётся **false** — звук клика по умолчанию выключен (как в Gboard); рекомендация ресерча флипнуть — отклонена; включение — через тумблер настроек в фазе 10. - **Панель уже перекрашена фазой 6 через атрибуты** (`popupPanelBackgroundColor` → `ios_keyboard_background_secondary`, pressed → `ios_key_normal_pressed`); рекомендованный ресерчем остаток — собственный `ios_popup_panel_background.xml` (радиус семейства 5dp вместо `button_corner_radius_lxx` 6dp + консистентность с drawable-семейством фазы 6), чтобы не менять общий drawable шести старых тем.
- Палитра: цвета `ios_*` уже существуют с полным night-паритетом (`values/colors.xml:57-70` ↔ `values-night/colors.xml:34-47`) — баллон = `ios_key_normal` (#FFF light / #6B6B6B dark), тень = `ios_key_shadow`; **новые цвета по возможности не заводить**; если понадобится — только парой values/values-night (parity-чек в Task 2).
