# Plan 05-01 — Жесты и multi-touch: double-space→период, свайп-дефолт, верификация (wave 1)

**Goal:** Закрыть INPUT-05..07 по вердиктам 05-RESEARCH.md: (1) **единственная кодовая работа** — восстановить вырезанный rkkr double-space→period в InputLogic по AOSP-паттерну (INPUT-05 GAP); (2) конфиг-флип — `pref_space_swipe` default false→true в трёх согласованных местах (INPUT-06 WORKS/GAP-default); (3) INPUT-07 WORKS — только структурная верификация; плюс сборка, boundary-check дифа и отложенный UAT-чекпойнт.

**User story:** As a татароязычный пользователь, я быстро печатаю двумя пальцами без потери букв, ставлю точку двойным пробелом и двигаю курсор свайпом по пробелу — сразу после установки, без копания в настройках.

**Красная линия:** диф кода фазы ограничен РОВНО пятью объявленными файлами (InputLogic.java, RichInputConnection.java — только если нужен аксессор, Settings.java, prefs_screen_preferences.xml, app_restrictions.xml). PointerTracker/PointerTrackerQueue/LatinIME/KeyboardState — работающая механика, не трогать. Boundary — механический diff-чек (Verification п.4).
