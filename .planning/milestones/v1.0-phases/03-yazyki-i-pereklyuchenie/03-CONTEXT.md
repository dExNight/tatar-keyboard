## Phase Scope

**Requirements:** LAYOUT-02, LAYOUT-03, SWITCH-01, SWITCH-02 (роадмап, фаза 3):

1. **LAYOUT-03** — русская (ЙЦУКЕН = east_slavic, СТАНДАРТНАЯ — без пятого ряда, по тексту требования) и английская (QWERTY) раскладки работают.
2. **LAYOUT-02** — long-press дубли: а→ә, о→ө, у→ү, ж→җ, н→ң, х→һ, э→ә, г→һ — на татарской И русской раскладках.
3. **SWITCH-01** — система видит три subtype tt_RU/ru/en_US; активная раскладка запоминается.
4. **SWITCH-02** — тап по глобусу циклит tt→ru→en; long-press глобуса — системный IME-пикер.

## Fixed by requirements/research (не грей-зоны)

- Русская раскладка — стандартная ЙЦУКЕН без пятого ряда; татарские буквы на ней только через long-press (текст LAYOUT-03 + ресерч 05 §4.5 п.2).
- Маппинги long-press зафиксированы текстом LAYOUT-02. В татарской раскладке инверсию пар (ж→җ основная и т.п.) НЕ делать — требование говорит «дубли», пятый ряд уже даёт прямой ввод.
- **Ревью F1 (фаза 2):** на татарской раскладке ё и ъ сейчас недостижимы — long-press е→ё и ь→ъ добавить в scope LAYOUT-02 татарской раскладки (у east_slavic это делает !text/ механизм — проверить, как донор вешает ё/ъ).
- Locale-строки: tt_RU/ru/en_US per SWITCH-01; в фазе 2 зарегистрирован голый "tt" — фаза 3 решает переход tt→tt_RU (ресерч фазы 2, open Q2).
- Активная раскладка хранится в prefs `pref_enabled_subtypes` (механизм форка, найден в ресерче фазы 2).
