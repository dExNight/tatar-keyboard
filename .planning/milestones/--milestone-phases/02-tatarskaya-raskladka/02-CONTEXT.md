## Grounding (проверено по коду форка)

- Формат раскладок форка уже «данные, не код»: `kbd_<name>.xml` (switch по showNumberRow) → `rows_<name>.xml` (структура рядов, ширины) → `rowkeys_<name>N.xml` (буквы). Русская ЙЦУКЕН = `east_slavic` (kbd_east_slavic, rows_east_slavic, rowkeys_east_slavic1–3, keyboard_layout_set_east_slavic).
- Татарскую раскладку строить по этому же паттерну: `kbd_tatar.xml` / `rows_tatar.xml` (пятый ряд + include рядов east_slavic либо копия) / `rowkeys_tatar*.xml` + `keyboard_layout_set_tatar.xml`. Это и есть выполнение LAYOUT-05 — новая раскладка добавляется файлами XML.
- `method.xml` сейчас содержит один subtype без locale — назначение tt-раскладки активной в MVP-фазе 2 решить минимальным способом (напр. subtype с `KeyboardLayoutSet=tatar`); полноценные три subtype — фаза 3.
- Слои `?123`/`#+=` у форка общие (kbd_symbols и пр.) — ожидается работа «из коробки», но проверить переходы с новой раскладки.
- Пятый ряд: 6 клавиш, ширина 16.667%p либо с учётом краёв; высоту ряда можно уменьшить (~0.75–0.8 буквенного) по ресерчу 05 §4.5 — на усмотрение планировщика с оглядкой на существующие механизмы rowHeight/bonusHeight форка (без нового кода, если возможно).
- Кодпоинты: Ә U+04D8/04D9, Ө U+04E8/04E9, Ү U+04AE/04AF, Җ U+0496/0497, Ң U+04A2/04A3, Һ U+04BA/04BB; регистр конвертируется штатно; Roboto покрывает.
